Ed. 106 · Para que + subjuntivo

Guia detalhado de estudo

Explique finalidade com para que

Para que + subjuntivo apresenta o objetivo de uma ação realizada por outro sujeito: Te envío el enlace para que puedas revisarlo. Quando o sujeito é o mesmo nas duas ações, use frequentemente para + infinitivo: Estudio para aprender; salí temprano para llegar a tiempo.

Compare: Trabajo para ahorrar (eu trabalho e eu economizo) com Te doy el mapa para que encuentres el hotel (eu dou; você encontra). Essa diferença de sujeito ajuda a escolher. O verbo depois de para que concorda com quem realizará a ação.

Prática

Complete: Te explico esto para que ___ (entender) el plan. Reformule “Estudo para melhorar”. Respostas: entiendas; Estudio para mejorar.
